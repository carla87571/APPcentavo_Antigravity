# auth-service 🔐

Microservicio de **autenticación y gestión de credenciales** para Centavo.

## Endpoints

- `POST /auth/login` (o `/api/auth/login`): Iniciar sesión.
- `GET /auth/me`: Obtener usuario del token JWT.
- `GET /health`: Estado del servicio.
